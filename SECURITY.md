# Security policy

This project is under active development. GitHub Actions test artifacts are **unsigned, experimental and not host-qualified** unless explicitly documented for a particular artifact digest. Do not use them in environments requiring trusted code-signing or production assurances.

For a suspected vulnerability, report privately using GitHub's **Report a vulnerability** / private vulnerability reporting feature **if enabled**, or contact the repository maintainer through an established private channel. Do not post exploit details, keys, personal data, or live service credentials in public issues. There is currently no formal SLA; maintainers will triage according to severity and exposure. Verified fixes should include a clear affected-version range, tests, and a source/binary attribution chain.

No signed releases are currently published. Security scans and attestations (when available) report bounded facts, not a guarantee of vulnerability freedom.
