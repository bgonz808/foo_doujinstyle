# foo_doujinstyle

A [foobar2000](https://www.foobar2000.org/) component for discovering DoujinStyle music releases and playing tracks from supported remote archives.

## What it does

- Search releases and browse monthly and all-time charts.
- Explore release artwork, tags, and available tracks.
- Index audio files inside remote ZIP archives, including supported MediaFire and public MEGA links.
- Add lightweight `.djt` track references to your foobar2000 Media Library. Playback streams the selected archive member through your installed decoders.
- Maintain a local catalog and refresh or repair track metadata.

After installation, open **Library → Search DoujinStyle…** to explore releases.

## Status

**Work in progress.** The project targets foobar2000 2.x on Windows. Builds and playback are still being tested, including Windows-on-ARM compatibility. No public release is available yet.
