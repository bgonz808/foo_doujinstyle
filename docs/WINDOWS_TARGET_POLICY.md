OS compatibility policy: VS2026/v145 toolsets no longer target Windows 7/8/8.1, although foobar2000 itself still supports Windows 7+. Preserve x86/x64 legacy-targeting compiler until compatibility is explicitly retired. ARM64EC runs natively only on Windows 11 ARM; foobar2000 ARM64EC accepts an x64 component via emulation. Build runner OS is not the produced binary's minimum OS. The disposable toolchain-probe CI compares installed MSVC CRT candidates and minimal /MD /Qspectre ARM64EC linking, NOT the six-PE BinSkim release or host E2E. Pin and qualify exact compiler, linker and CRT versions before upgrading production. Sources: https://learn.microsoft.com/en-us/cpp/overview/supported-platforms-visual-cpp ; https://learn.microsoft.com/en-us/windows/arm/arm64ec ; https://www.foobar2000.org/windows .
